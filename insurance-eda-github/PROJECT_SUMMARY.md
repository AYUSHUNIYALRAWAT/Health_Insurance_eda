# Project Summary

## Title
Insurance Data Analysis & Exploratory Data Analysis (EDA)

## Objective
Explore, clean, visualize, and transform an insurance dataset using Python.

## Dataset
- Rows before duplicate removal: 1,338
- Columns: 7
- Missing values: 0
- Duplicate rows: 1
- Rows after duplicate removal: 1,337

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Main Tasks
1. Load and inspect the dataset.
2. Check dimensions, data types, statistics, missing values, and columns.
3. Visualize numerical and categorical variables.
4. Inspect potential outliers.
5. Analyze numerical correlations.
6. Remove duplicate records.
7. Clean and encode categorical variables.
8. One-hot encode region.
9. Create BMI categories.
10. Convert the final engineered dataset to integer values.

## Scope
This is an EDA and preprocessing project. No predictive model is implemented in the current notebook.
